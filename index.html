Aplikasi Web Progresif (PWA)

Instal Sebagai Aplikasi

Jalankan layar penuh tanpa bilah browser di laptop, tablet, atau smartboard kelas.

Instalasi Satu Klik (Chrome / Edge)

Klik tombol di samping untuk memasang pintasan aplikasi ke perangkat ini.

Panduan Instal Manual & Buat Pintasan

1
Google Chrome Desktop (Windows / Mac / Chromebook): Klik ikon ⋮ di pojok kanan atas → pilih Simpan dan bagikan → klik Instal halaman sebagai aplikasi... atau Buat pintasan... (centang Buka sebagai jendela).
2
Chrome Android (HP / Tablet): Ketuk ikon ⋮ → pilih Instal aplikasi atau Tambahkan ke layar utama.
3
Safari iPad / iPhone (iOS): Ketuk tombol Bagikan (Share) di bilah menu → gulir ke bawah dan ketuk Tambah ke Layar Utama.
Paket Upload GitHub Pages & Mode Offline Siap Upload

Cukup unggah index.html ke repositori GitHub Pages Anda. Jika ingin dukungan penuh tanpa internet (offline) di kelas, unduh juga manifest.json dan sw.js lalu letakkan di folder yang sama.
