Instal Sebagai Aplikasi

Tampil layar penuh tanpa bilah browser di HP, tablet, maupun laptop.

Siap Dipasang Langsung ke Perangkat!

Klik tombol hijau untuk menambahkan ikon ke layar utama / desktop.

1
Chrome Android (HP & Tablet): Ketuk ikon titik tiga ⋮ di pojok kanan atas browser → pilih Instal aplikasi atau Tambahkan ke layar utama.
2
Safari iPhone & iPad (iOS): Ketuk tombol Bagikan (Share ⬆) di bilah bawah/atas → gulir ke bawah dan ketuk Tambah ke Layar Utama.
1
Cara Tercepat (Ikon Address Bar): Klik ikon Instal Aplikasi (Monitor + Panah Bawah) di sisi kanan bilah alamat URL Chrome atau Microsoft Edge.
2
Lewat Menu Chrome / Buat Pintasan: Klik ⋮ di pojok kanan atas → pilih Simpan dan bagikan → klik Instal halaman sebagai aplikasi... atau Buat pintasan... (centang Buka sebagai jendela).

Unggah index.html ke repositori GitHub Anda lalu aktifkan Settings → Pages. Untuk dukungan 100% offline di kelas tanpa internet, sertakan juga manifest.json dan sw.js di folder yang sama.
